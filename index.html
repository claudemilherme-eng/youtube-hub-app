Youtube Hub

Personal YouTube upload scheduling tool

English

Youtube Hub is a personal, non-commercial tool used by its owner to upload and schedule videos on the owner's own YouTube channels, and to read basic statistics of those same channels. It is not offered to the public and does not access any channel that does not belong to the owner.

The tool uses the YouTube Data API v3 and the YouTube Analytics API, authorized by the owner through Google OAuth. Access tokens are stored only on the owner's computer.

Português

O Youtube Hub é uma ferramenta pessoal e não comercial, usada pelo próprio dono para enviar e agendar vídeos nos seus próprios canais do YouTube e para ler estatísticas básicas desses mesmos canais. Ela não é oferecida ao público e não acessa nenhum canal que não pertença ao dono.

A ferramenta usa a YouTube Data API v3 e a YouTube Analytics API, autorizadas pelo dono via Google OAuth. Os tokens de acesso ficam guardados apenas no computador do dono.
